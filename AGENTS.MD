# AGENTS.MD

## Regla de Sincronización con GitHub

Cada acción, cambio, creación de archivo o avance realizado en este proyecto **debe quedar reflejado con un `git commit` y `git push`** al repositorio remoto:

- **Repositorio:** https://github.com/S-Baltazar/apocaliptic-president

### Flujo obligatorio tras cada cambio
1. Verificar que no se incluyan archivos temporales o dependencias (`node_modules/`, `dist/`, `.env`).
2. Ejecutar `git add .`
3. Ejecutar `git commit -m "<descripción clara del cambio>"`
4. Ejecutar `git push` hacia `origin` (`https://github.com/S-Baltazar/apocaliptic-president`).
